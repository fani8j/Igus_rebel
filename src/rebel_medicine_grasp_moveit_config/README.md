# MoveIt - medicine grasp (rebel_medicine_grasp_moveit_config)

MoveIt 2 (Humble) configuration, ros2_control config and **plan-only** launch for **shelf picking of medical cartons** with the dual-arm igus ReBeL stand on a D200 AMR:
left arm = suction tool v5, right arm = SMC LEHF20K2-48 gripper. Model: `rebel_medicine_grasp_description`. Mock hardware or Isaac topics only; no real-hardware path.

## How it differs from the cutting config (`rebel_dual_arm_stand_moveit_config`)
| | cutting | medicine grasp |
|---|---|---|
| tools | XEG/SMC gripper, knife, 2 cameras on both arms | left suction tool v5, right LEHF gripper; no knife |
| group tips | `arm_*_knife_tip` | `arm_left` -> `arm_left_suction_tcp`, `arm_right` -> `arm_right_gripper_tcp` |
| gripper | none | group `right_gripper` (`arm_right_finger_left_joint`, mimic follower in the URDF), controller `right_gripper_controller` |
| world | stand origin | `world` = `d200_base_footprint` (stand mounted on the D200 AMR) |
| scene | carton + table (`cell_scene.yaml`) | shelf + plinth + 5 packed cartons (`medicine_shelf_scene.yaml`) |
| launch | `dual_arm.launch.py` | `medicine_grasp.launch.py`; arg `add_cell_scene` -> `add_medicine_shelf` (+ `pull_out`), no `tool_config` |
| OMPL | default segment resolution | `longest_valid_segment_fraction: 0.001` for both arms (thin shelf boards) |
| other | | the same limits, Pilz cartesian limits, KDL, 200 Hz controllers |

## Launch (always an unused domain, never the robot's)
```bash
export ROS_DOMAIN_ID=171 ROS_LOCALHOST_ONLY=1
source /opt/ros/humble/setup.bash && source <ws>/install/setup.bash      # <ws> path must not contain spaces (see below)
ros2 launch rebel_medicine_grasp_moveit_config medicine_grasp.launch.py hardware_protocol:=mock_hardware            # plan-only
ros2 launch rebel_medicine_grasp_moveit_config medicine_grasp.launch.py use_rviz:=true pull_out:=0.1                # RViz "MoveIt - medicine grasp", target carton pulled out 100 mm
ros2 launch ... hardware_protocol:=isaac_topic use_sim_time:=true                                                   # needs the finger-name mapping, see the description README
python3 $(ros2 pkg prefix rebel_medicine_grasp_moveit_config)/share/rebel_medicine_grasp_moveit_config/scripts/verify_plan_only.py --out result.json      # plan-only checks
```
Args: `hardware_protocol` (mock_hardware|isaac_topic), `use_sim_time`, `allow_trajectory_execution` (**default false = plan-only**: move_group is given no controller manager, so even a
stray `/execute_trajectory` cannot reach a controller), `run_move_group`, `use_rviz`, `rviz_config`, `add_medicine_shelf`, `scene_file`, `pull_out`. The launch logs
"MoveIt - medicine grasp: ...". The robot description is expanded with a subprocess argument list, so install paths with spaces are fine for the URDF; **mesh loading
(`file:///...`) still fails for paths with spaces**, so use a space-free path to the install space (the scratch workspace on the external drive is reached through a symlink).

## Contents
* `config/rebel_medicine_grasp.srdf` - generated by `scripts/make_srdf.py`. Groups `gantry` (lift + 2 sliders), `arm_left` (chain `arm_left_base_link` -> `arm_left_suction_tcp`), `arm_right`
  (-> `arm_right_gripper_tcp`), `dual_arm` (gantry + both arms), `right_gripper` (`arm_right_finger_left_joint`), `left_suction_tool` (link group). End effectors `left_suction`
  (parent `arm_left_link6`, group `left_suction_tool`) and `right_gripper_ee` (parent `arm_right_link6`, group `right_gripper`). States: `home` for gantry/arms/dual_arm (lift -0.2, sliders
  -0.005973 / +0.005973, arms upright), `gripper_open` (q 0.024, pad gap 56 mm), `gripper_closed` (q 0, 8 mm).
* **Collision matrix** (130 disabled pairs, same conservative policy as the cutting config, no sampling): all joint-adjacent pairs; the head-camera parts among themselves; the arm-internal
  pairs of our single-arm SRDF per arm; tool links of one arm among each other (`gripper_base`/`finger_left`/`finger_right`; `finger_left`<->`finger_right` is "Adjacent" because the two
  jaw hulls overlap by design, below 18.4 mm per finger); `d200_base_link` <-> `stand` and <-> both arm base links. **Left enabled on purpose**: tool vs link5/link4, fingers vs link6,
  tool vs the other arm, stand vs sliders, lift/sliders/arms vs the AMR box, everything vs shelf and cartons.
* `config/kinematics.yaml` (KDL per arm), `joint_limits.yaml` (arm 0.785 rad/s, 5.24 rad/s^2 as in the stand config; gantry 0.3 m/s, 0.5 m/s^2; **finger 0.04 m/s**, 0.5 m/s^2; URDF finger
  limit 0..0.024 m, 0.05 m/s), `pilz_cartesian_limits.yaml` (0.05 m/s, unchanged), `ompl_planning.yaml`, `pilz_planning.yaml`.
* `config/ros2_controllers.yaml`, `moveit_controllers.yaml`: `gantry_`, `arm_left_`, `arm_right_trajectory_controller` and `right_gripper_controller` - a `JointTrajectoryController` on
  `arm_right_finger_left_joint` (chosen over `GripperActionController`: plain FollowJointTrajectory for MoveIt, works unchanged with mock_hardware; verified active).
* `config/initial_positions.yaml` - home with the gripper open (fingers 0.024).
* `config/medicine_shelf_scene.yaml`, `scripts/add_medicine_shelf.py`, **`config/medicine_shelf_pose.json`** - see below.
* `scripts/verify_plan_only.py` (plan-only checks and the placement search), `scripts/make_srdf.py`, `test/check_scene_pose.py`.

## Planning scene and shelf placement
Objects (frame `world` = `d200_base_footprint`): `medicine_shelf` (floor, back, two sides, top boards), `shelf_plinth`, `carton_0..4` (packed, zero gap, sequence boxes [1,2,3,5,1] of
`common/params.py` BOXES, **`carton_2` = target = box 3 Terumo Accuforce 16 x 220 x 250 mm**). Shelf geometry and the carton layout are copied from the Isaac `shelf_cartons.usda`.
`pull_out:=0.1` moves the target 100 mm out toward the robot (the handoff state).

**Pose** (shelf frame W: origin on the shelf floor at the front edge, centred on the target, +X lateral, +Y into the shelf): `world_T_W` = translation **(0.78, 0.0, 1.05) m**, yaw **-90 deg**
(W +Y = AMR +X). Shelf floor top z = 1.05 m, target spine centre (0.78, 0, 1.16), carton top 1.27 m. The **AMR parks with its front facing the shelf**, shelf centred on the AMR centre line,
midway between the two arms (0.222 m from each arm axis); the shelf (front board at x 0.771, plinth front at x 0.74) is >= 0.256 m from the AMR front face (x 0.484); with the target pulled out
the clearance is >= 0.196 m (required >= 0.05 m, tested). Exported to `config/medicine_shelf_pose.json` (frame `d200_base_footprint`, xyz, yaw, board heights, carton layout, AMR clearance)
by `add_medicine_shelf.py --write-pose-json`, for the Isaac scene. This differs from the Isaac rig placement (shelf 0.40 m ahead of the left arm axis, spine at arm shoulder height): moved
onto the AMR it is straight ahead of the left arm (too close to the shoulder for a horizontal suction approach) and too high for the right gripper pointing down (its TCP must stay below ~1.35 m).
The placement came from `verify_plan_only.py --search` (collision-aware IK over x 0.70-0.94, y -0.05..0.10, floor 1.00-1.10): both tools reach for x 0.78, y -0.05..0.05, floor 1.00-1.05.

## Verification (plan only, nothing executed; results in `scan_results/medicine_grasp_moveit_20261015/`)
`verify_plan_only.py`: `arm_left` home -> pre-grasp (suction_tcp 50 mm before the spine, tool z into the spine, OMPL) -> Pilz LIN to 3 mm before contact and LIN to contact with the pads pressed
5 mm (the suction tool <-> target carton pair allowed in the ACM for that one motion only, removed afterwards; without the allowance the LIN is rejected); `arm_right` home -> gripper_tcp above the
pulled-out carton (stop face 4 mm above the top edge + 100 mm, then the final handoff pose, gripper open); `right_gripper` open -> closed; every waypoint of every arm plan through
`/check_state_validity` (0 states touching `d200_base_link`); a probe box overlapping the AMR deck must be reported as a contact with `d200_base_link` (it is). OMPL results are re-requested
when move_group's path validation rejects a re-sampled path (up to 3 times; reported as `attempts`).

## ASSUMED
* AMR parking: front facing the shelf, centred; AMR static (no navigation planning); lift fixed at the home value -0.2 m (moving the lift moves the arms, not the shelf).
* Shelf boards, plinth (0.3 x 0.4 m, top 20 mm under the shelf floor), carton sizes/order and the 0 mm packing gap come from the Isaac scene / CAD params; carton 3D shape = bounding box.
* Pre-grasp distance 50 mm, press 5 mm, handoff pulled-out 100 mm, stop gap 4 mm, pad centre 42.5 mm behind the spine: from `common/handoff.py` / the gripper README.
* Tool orientation conventions of `handoff.py` (suction tool x = up, z = into the spine; gripper z down, stroke along the shelf X); both 180-deg variants about the tool axis are tried.
* Finger velocity limit 0.04 m/s in MoveIt (URDF 0.05); gantry/Pilz limits are inherited unchanged; none was loosened.
* Collision-free planning here is not blade/pad-clearance proof for the real shelf (cartons are boxes, neighbours may stand 15 mm proud in reality - not modelled).
* The scene is a static copy of the CAD numbers; the real shelf position relative to the AMR is unknown.
