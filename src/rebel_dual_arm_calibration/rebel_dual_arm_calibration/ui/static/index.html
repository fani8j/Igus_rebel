TCP pivot calibration

Finds the knife tip r in igus_tool0 from poses where the SAME physical tip is re-seated in a fixed countersink fixture. The buttons of this tab never move the robot. You position the arm yourself with the Servo teleop keyboard (recommended: ros2 run igus_rebel_moveit_config rebel_servo_teleop_keyboard) or with the jog panel on this page (its usual enable rules apply), lift the tip out and re-seat it in the fixture between poses (do not rotate about the tip), release the keys, then capture. Ultrasonic stays OFF.

      Captured poses

      Capture

      Needs the whole checklist ticked, the arm still for 2.0 s (< 2 mrad), fresh TF, and a tool rotation of at least 15° from every stored pose.

      FIT poses are used by the solve; VALIDATE poses are held out and only measure the error. Aim for 8–12 FIT and 3–4 VALIDATE poses.

      Solve

      Mechanical sanity check

      Measure with calipers: flange face to blade tip, along the flange axis. The current URDF implies 183.4 mm; an old pivot data set suggested about 168 mm (a ~15 mm z question is open).

      Output

      Writes tcp_result_<arm>.yaml into the session directory only (only GOOD / PASS results). The UI never edits the xacro: you apply the diff by hand.
